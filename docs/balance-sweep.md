## How to read this

- **Confidence tiers**: *modeled* (analytic, exact given the engine) · *modeled($/hr)* (pace only) · *proc* (Layer 5 estimate: fires/hour × value per fire, assumptions below) · *partial* · *not modeled* (economy / cursors / one-shots — listed, not scored).
